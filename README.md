# Claude Code Made Simple: companion files

The starter folders for every project in the book. Each one has:

- `README.md`: the spec you give Claude Code
- `tests/`: acceptance tests. Your project is done when `npm test` passes. Don't change them.
- any data files the project needs

Start a project like this:

```
cd projects/p1-expense-report
claude
```

Then follow the chapter. Claude's code will look different from anyone else's, and that's fine:
the tests check what your program does, not how it was written.

Checked with Claude Code 2.1.296 (2026-10-13).
What changed since printing: https://reid-weston.github.io/claude-code-made-simple/
The starter files are free to use, change and share (MIT license).
